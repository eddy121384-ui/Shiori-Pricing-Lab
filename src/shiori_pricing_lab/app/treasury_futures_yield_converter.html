Treasury Futures ↔ CTD Yield Converter

用 CTD coupon、maturity、conversion factor、last delivery date，把 CBOT Treasury futures price 換成 CTD implied yield；也可以反推「殖利率到某個水準時，期貨價格大概在哪」。這是交易室快速 sanity check，不是正式估值系統。

1. Inputs

口徑：CTD clean price ≈ futures price × conversion factor + net basis；再用半年度 coupon、Actual/Actual coupon accrual approximation 解 YTM。

3. Manual CTD JSON override

如果直接用 file:// 打開 HTML 讀不到 JSON，請從 repo root 執行 python -m http.server 8000，或把 CTD JSON 貼到下面。
