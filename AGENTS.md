# AGENTS.md

Rules for AI coding agents working in this repository:

1. Eddy's latest explicit decision is authoritative.
2. Work on the current requested outcome directly.
3. Pricing and risk numbers must come from deterministic code.
4. Do not fabricate market data or Bloomberg evidence.
5. Pricing-method changes require deterministic tests and Eddy's approval.
6. UI, visual, tooling, and documentation work should use the simplest direct path.
7. Do not create speculative frameworks, documents, issues, or process.
8. Agents may choose ordinary implementation details freely.
9. Do not merge without Eddy's explicit approval.
